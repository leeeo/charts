# 소개 사이트 디자인 기준

leeeo 공통 기준(`leeeo-ui` DESIGN.md 0.2.0)을 따른다. 새 토큰을 만들지 않고 사이즈표와 같은 종이·먹·연두 값을 쓴다.

- 셸: `vendor/`의 leeeo chrome v1.1(`chrome.css`·`chrome.js`·`theme.js`, 사이즈표에서 복사). 헤더는 앱 이름(공통 차트)만,
  `leeeo`는 푸터의 `© 2026 leeeo`(허브 https://leeeo.app/ 링크)에만. 테마는 시스템·밝게·어둡게 선택, 키 `leeeo-theme`.
- 토큰: `site.css` 첫 블록. 글자 14/15/17/18/24·26/30·40px, 간격 4px 배수, 모서리 8/16px, 터치 44px, 초점 3px.
- 차트 색: 페이지의 `--accent`를 정의하지 않는다. 연두(`--lime`)는 버튼 전용이고, 차트는 라이브러리 기본 시리즈 색을 쓴다.
- 갤러리: 카드마다 밝은 칸·어두운 칸·스펙 JSON. 칸의 테마는 페이지 테마와 무관하게 고정하며 색 값은 `src/chart.css`와 같다.
- 상태: 선택·활성은 배경 농도와 글자로만 표시한다. 색 테두리 강조를 쓰지 않는다(오류 입력칸의 빨간 테두리는 오류 문구와 함께 쓴다).
- 움직임: 차트의 그리기 애니메이션만 있고 `prefers-reduced-motion`을 따른다. 장식 애니메이션은 없다.
- 접근성 제약: 한글 `word-break: keep-all`, 제목 `text-wrap: balance`, 코드 블록은 키보드로 초점·스크롤 가능.
- 남은 부채: 모바일 페이지가 길다(차트 8종 × 2칸). 스펙 JSON은 모바일에서 16rem 높이로 잘라 안에서 스크롤한다.
